<h2>
    <font color= "#EA5E27" size="3">2.</font>
    <span>核心功能</span>
</h2>

<h3>
    <font color= "#EA5E27" size="2">2.1</font>
    <span>服务器状态监控</span>
</h3>
<p>实时查看服务器运行状态，一目了然掌握主机健康情况：</p>
<ul>
    <li><b>CPU 监控</b>：型号、核心数、实时使用率、频率、温度</li>
    <li><b>内存监控</b>：总内存、已用/可用内存、Swap 用量</li>
    <li><b>磁盘监控</b>：各分区用量、读写速率、磁盘健康状态</li>
    <li><b>网络监控</b>：各网卡实时上下行速率、总流量、当前连接数</li>
    <li><b>系统负载</b>：运行时长、平均负载</li>
    <li>所有指标支持<b>实时刷新</b>，状态变化即时可见</li>
</ul>

<h3>
    <font color= "#EA5E27" size="2">2.2</font>
    <span>用户与权限管理</span>
</h3>
<p>多用户协作，分级管控，保障服务器安全：</p>
<ul>
    <li><b>用户账户</b>：支持注册、登录、个人信息管理</li>
    <li><b>角色管理</b>：内置管理员、运维人员、只读用户等预设角色</li>
    <li><b>细粒度权限</b>：可自定义角色权限，精确控制每位用户能访问的功能模块</li>
    <li><b>安全登录</b>：密码加密存储，Token 鉴权，会话管理</li>
</ul>

<h3>
    <font color= "#EA5E27" size="2">2.3</font>
    <span>子进程与任务管理</span>
</h3>
<p>轻松管理服务器上运行的服务和应用：</p>
<ul>
    <li><b>进程管理</b>：创建、启动、停止、重启服务器上的应用程序</li>
    <li><b>进程监控</b>：查看进程运行状态、CPU/内存占用、运行日志</li>
    <li><b>崩溃自动恢复</b>：关键进程异常退出时自动重启</li>
    <li><b>任务调度</b>：支持创建异步任务，设置优先级和超时时间</li>
    <li><b>任务历史</b>：查询任务执行记录，方便排障与审计</li>
</ul>

<h3>
    <font color= "#EA5E27" size="2">2.4</font>
    <span>网络管理</span>
</h3>
<p>内网穿透与隧道管理，让您的服务随时随地可访问：</p>
<ul>
    <li><b>隧道配置</b>：创建和管理 Frpc 内网穿透隧道，支持 TCP/UDP/HTTP/HTTPS 协议</li>
    <li><b>连接监控</b>：实时查看各隧道在线状态、连接时长与流量</li>
    <li><b>流量统计</b>：按日/周/月查看隧道流量历史</li>
    <li><b>配置备份</b>：支持隧道配置的导入导出，方便迁移</li>
    <li><b>异常告警</b>：隧道断开时自动记录告警</li>
</ul>

<h3>
    <font color= "#EA5E27" size="2">2.5</font>
    <span>快捷应用</span>
</h3>
<p>将常用命令或操作保存为快捷方式，一键执行：</p>
<ul>
    <li>创建自定义快捷应用，支持自定义图标</li>
    <li>两种展示方式：命令列表模式、图标网格模式</li>
    <li>便捷的 App 管理（增删改查）</li>
</ul>

<h3>
    <font color= "#EA5E27" size="2">2.6</font>
    <span>远程终端</span>
</h3>
<p>浏览器内置终端，随时随地远程操作服务器。</p>
